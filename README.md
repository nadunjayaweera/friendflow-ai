# FriendFlow AI

FriendFlow is a privacy-first AI task organizer built for the
Hacktoberfest 2026 Weekend Challenge: Build for a Friend.

## Problem

My friend often receives messages and notes containing several tasks
and finds it difficult to organize them into actionable items.

## Solution

FriendFlow uses an open-weight AI model running locally to convert
unstructured notes into structured tasks.

## Tech Stack

- React
- Node.js
- Express
- Ollama
- Gemma
- LocalStorage

## Why Local AI?

The user's personal notes can be processed locally without being sent
to a third-party AI provider.
